ESP32-C3 Super Mini + 1.54″ ST7789　浏览器直刷，无需任何驱动

烧录步骤

  1. 用 USB 线把 ESP32-C3 Super Mini 连到电脑（板子不用按任何键）。
  2. 请使用 Chrome / Edge / Firefox（不支持 Safari / iOS）。
  3. 点击下面按钮 → 选择设备对应串口（如 COM3 · ESP32-Serial）。
  4. 烧录完成设备自动重启，本页将自动弹出 WiFi 配置窗口。
  5. 填入你家 WiFi 与密码，设备联网后浏览器会自动打开配置页。
当前浏览器不支持 WebSerial，请改用 Chrome / Edge 打开本页。
当前版本：–　·　推送代码后本页自动部署最新固件。

换环境 / 切换 WiFi（配置都会保留）

Keep Config

设备若送人 / 搬家换网络，不用重新配置：只需要重连新 WiFi。

下面的按钮可再次连接设备，只更新 WiFi 账号密码，已保存的天气 API Key、城市/地址、行情、主题全部保留。

当前浏览器不支持 WebSerial，请改用 Chrome / Edge 打开本页。

接线方式：USB 连电脑后点击按钮 → 选择对应串口 → 在弹出的 WiFi 列表里选 新环境的网络并输密码即可。若设备正连着旧 WiFi，也会先进入配网等待界面。

无电脑时的兜底：按住 BOOT 键再上电进入热点（WiFi WeatherClock-xxxx， 访问 192.168.4.1）切换 WiFi，同样保留全部配置。

配网后：补填天气

Config

WiFi 配好后自动打开设备页（http://设备IP），填写：

· 和风天气 API Key（dev.qweather.com 免费申请）

· 城市名（如 北京），或点「定位」自动识别、填经纬度

点「保存并重启」即可显示时间与天气。之后访问 http://weatherclock.local 可随时改配置。

兜底：按住 BOOT 键再上电进入热点模式（WiFi WeatherClock-xxxx，访问 192.168.4.1）。

提示：行情（金价/沪铜/布油）与天气一样在配置页维护，支持最多 6 个行情槽、设置轮播间隔。桌面版 Chrome / Edge / Firefox 效果最佳；Android Chrome 首次未弹「连接设置」时检查 about:flags/#enable-serial-api。遇到问题可查看串口日志，或 项目主页。
