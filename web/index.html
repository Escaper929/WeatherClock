🌤 WeatherClock 一键刷固件

ESP32-C3 Super Mini + 1.54″ ST7789 · 浏览器直刷（WebSerial）

  1. 用 USB 线把 ESP32-C3 Super Mini 连接到电脑（板子不用按任何键）。
  2. 浏览器用 Chrome / Edge / Firefox 打开本页（不支持 Safari / iOS）。
  3. 点击下面绿色按钮 → 选择设备对应的串口（如 COM3 · ESP32-Serial）。
  4. 等待烧录完成，设备会自动重启并进入配置门户。
当前浏览器不支持 WebSerial，请改用 Chrome / Edge 打开本页。
版本：– · 更新方法：推送代码即可自动重新编译并部署最新固件到本页。

📱 烧录后：配置天气

首次使用设备会自动建一个 WiFi：WeatherClock-xx（密码留空，直接连接）。 然后手机/电脑浏览器打开 http://192.168.4.1，填写：
· WiFi 名称/密码
· 和风天气 API Key（在 dev.qweather.com 免费申请）
· 城市名（如 北京）
点“保存并重启”，设备即可联网显示时间和天气。
以后想改配置：按住 BOOT 键再上电，即可重新进入配置门户。
使用 Chrome / Edge / Firefox 桌面版效果最佳。若手机（Android Chrome）首次未弹“连接设置”，请检查 about:flags/#enable-serial-api（部分版本需手动开启）。遇到问题可查看串口日志。项目主页
